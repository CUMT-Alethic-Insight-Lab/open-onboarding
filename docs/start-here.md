# 从这里开始

本仓提供学习顺序，不替你决定研究方向。先完成公共基础，再选一个方向；[awesome-ai](https://github.com/CUMT-Alethic-Insight-Lab/awesome-ai) 是延伸资源索引。当前所有新课程均为 **内容完成，待试走**，尚未声称“新生已验证”。

## 1. 先确认入口

| 我的情况 | 先做什么 | 不要做什么 |
| --- | --- | --- |
| 没写过 Python 或没配环境 | [公共先修](foundations/prerequisites.md) 的 PR-00…02 | 先装大型训练框架、先读前沿论文 |
| 会 Python，不懂 ML | 先修自检 → [经典机器学习](foundations/classical-ml.md) → [神经网络](foundations/neural-networks.md) | 用库跑通一次就跳过评估 |
| 做过 sklearn 小实验 | 完成 ML-08 → DL-02/03 → 按方向选桥接 | 从模型名称直接跳大框架 |
| 只想先了解 AI | [学科地图](maps/field-map.md) → [多线发展史](history/ai-history.md) | 把历史年表当课程顺序 |
| 已确定方向 | 先修缺口自检 → [方向路径](paths/README.md) | 跳过入口要求的公共节点 |

## 2. 二十分钟的起点自检

1. 用 Python 写一个读取列表、返回均值的函数；说明列表推导式与生成器的差异。
2. 用 NumPy 计算 `(2,3) @ (3,4)` 的形状，解释矩阵乘法与逐元素乘法。
3. 解释导数、条件概率、期望与方差各回答什么问题；不会就回 PR-03…05，不必先读整本数学书。
4. 把一个数据表分成训练、验证、测试集，并说明为何预处理统计量不能先看测试集。
5. 用 Git 新建分支、提交一个小改动并查看 diff；参考[分支、提交与 PR](github/branch-commit-pr.md)。

第 1、2、4、5 项不能独立完成时，从公共先修开始；只会语法但数学生疏，可边做 ML-01 边回补。无需等待“全部数学学完”。

## 3. 公共学习闭环

```text
公共先修 → ML-00…08（含稳健实验毕业任务） → DL-00…09（含三个最小实现）
                                              ↓
                         方向桥接 / 数据工程 / 小模型与高效 AI
```

- [公共先修](foundations/prerequisites.md)：环境、Python/NumPy、线代、微积分、概率、数据/Git。
- [经典 ML](foundations/classical-ml.md)：任务与数据 → 模型 → 泛化与评估 → 树/集成 → 无监督 → 可复现交付。
- [神经网络](foundations/neural-networks.md)：MLP → 反传 → 训练闭环 → CNN/RNN/Attention → 训练范式。
- [数据工程](paths/data-engineering.md)：来源许可 → 清洗/去重 → 无泄漏拆分 → 版本化数据集。
- [小模型与高效 AI](paths/efficient-ai.md)：紧凑设计、压缩与同口径部署测量。
- [学科地图](maps/field-map.md)：范式、学习信号、架构、任务四条独立分类轴。
- [AI 发展史](history/ai-history.md)：理解技术背景，不代替先修。

## 4. 每个节点怎样学

1. 先读“前置、目标、为什么在这里学”，不满足前置就沿补救链接返回。
2. 必学材料读指定小节，学习动作必须留下手算、图、代码或指标表。
3. 对照“完成标准”口头解释；不能解释，就按“卡住时”定位缺口，不靠继续收藏资源解决。
4. 再做最小实践，保留命令、版本、seed、数据划分与输出；跑通不等于理解，更不等于完成新人试走。
5. 沿“下一步”前进。材料标为“推荐/深入”的可延后，不把整本教材当入口门槛。

## 5. 首次贡献

学习材料的纠错、断点报告与微型练习同样通过 PR。先读 [AI 辅助工作流](ai-assisted/workflow.md)：AI 可以协助，提交者仍需核实来源、运行命令、理解改动并声明。尚无真实新人试走记录时，不要自行把成熟度改为“新生已验证”。
