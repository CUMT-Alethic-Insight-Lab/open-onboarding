# 数据工程：从来源许可到可追溯数据集

**入口**：PR-00…02、ML-00/03；**出口**：一个 CPU 可复现的小型数据流水线；**状态**：内容完成，待试走。这里的“完成”是来源、规则、拆分、版本和审计都能解释，不是下载过大型语料。

最小项目使用本仓原创英文片段，不涉及爬站或个人数据。真实项目先完成 DE-00，未经许可/用途不明时不以“网上公开”替代授权判断。

## DE-00 来源、许可、隐私与用途

- **前置**：PR-02。
- **目标**：能记录来源、许可、授权范围、个人信息与撤回/保留约束。
- **为什么在这里学**：后续清洗不能消除无权使用或隐私风险。
- **指定材料**：必学 [Hugging Face Dataset Cards](https://huggingface.co/docs/hub/datasets-cards)、[DCLM](https://arxiv.org/abs/2406.11794) 的数据描述与治理讨论；推荐数据源自己的 license/terms 原文。
- **学习动作**：区分访问权限、著作权许可、隐私/伦理和项目用途限制；记录来源 URL、获取日期、作者、允许用途。
- **最小实践**：给最小样本写 dataset card 草稿，列出 synthetic 来源、许可、教学用途、无个人数据和局限。
- **完成标准**：每条数据可追溯到来源与处理依据；不确定的许可标待核验而不是默认可商用。
- **卡住时**：停止使用来源不明数据，换官方明确授权的小样本；不绕 robots、登录或访问控制。
- **下一步**：DE-01。
- **资源要求**：CPU，小型合法数据。

## DE-01 格式、Schema 与元数据

- **前置**：PR-01、DE-00。
- **目标**：能选择 CSV/JSONL/Parquet/Arrow，并用 schema 验证记录与元数据。
- **为什么在这里学**：格式影响类型、嵌套、列式扫描与复现，不能只看扩展名。
- **指定材料**：必学 [HF Datasets 文档](https://huggingface.co/docs/datasets/)、[pandas IO](https://pandas.pydata.org/docs/user_guide/io.html)、[Apache Arrow/Parquet](https://arrow.apache.org/docs/python/parquet.html)。
- **学习动作**：比较 CSV 的平面文本、JSONL 的逐行嵌套、Parquet 的列式类型；定义必填字段、类型、缺省与额外字段策略。
- **最小实践**：运行 `python examples/data_pipeline.py`，检查 JSONL schema、Parquet 写出/读回 ID 一致和 dataset card 元数据。
- **完成标准**：坏记录有计数与原因，不发生静默类型转换或丢字段；能说明 Arrow 作为内存表示与 Parquet 文件格式的关系。
- **卡住时**：先打印一条原始记录和 schema；编码统一 UTF-8，JSONL 不直接当普通 JSON 数组解析。
- **下一步**：DE-02。
- **资源要求**：CPU，pandas/pyarrow；示例无需联网。

## DE-02 清洗与标准化

- **前置**：DE-01。
- **目标**：能处理缺失、异常、编码、空文本、HTML 与格式归一化并审计丢弃。
- **为什么在这里学**：规则若不明确，所谓“高质量”不可复现。
- **指定材料**：必学 [FineWeb](https://arxiv.org/abs/2406.17557) 的过滤流程作为案例；推荐 [DataTrove](https://github.com/huggingface/datatrove) 的处理抽象。
- **学习动作**：按原样保留输入；NFKC、HTML/空白处理与内容过滤分别记录；区分技术无效与主观不喜欢。
- **最小实践**：在示例中定位空文本、过短文本，比较清洗前后记录与 `stats.json` 的原因计数。
- **完成标准**：能抽查保留/丢弃样例，规则改动会增加版本，不把异常一律删除而不审查。
- **卡住时**：回 DE-01 检查字段；规则误伤时缩小样本并写反例，不继续堆过滤条件。
- **下一步**：DE-03。
- **资源要求**：CPU。

## DE-03 精确与近似去重

- **前置**：DE-02；PR-03 的集合/向量直觉。
- **目标**：理解规范化 hash、MinHash/LSH 候选与最终相似度判断的边界。
- **为什么在这里学**：精确重复易去，近重复会污染训练和评测，但近似算法也会漏/误候选。
- **指定材料**：必学 [FineWeb](https://arxiv.org/abs/2406.17557) 的去重案例；推荐原始 [MinHash/LSH 概念说明（DCLM 相关流程）](https://arxiv.org/abs/2406.11794)。此处不要求读完整论文。
- **学习动作**：精确 hash 找规范化相同文本；MinHash 用多个签名和 banding 提候选，再计算 token Jaccard；候选不是最终判定。
- **最小实践**：示例比较 2 个精确重复与 2 个近重复，检查阈值、保留顺序、相似度和原因记录。
- **完成标准**：能解释 false positive/negative、shingle/token 粒度和阈值；不将语义改写等同字符串相似。
- **卡住时**：回 DE-02 统一清洗；候选太多减少误报先看 band/rows，不能盲目调高阈值。
- **下一步**：DE-04。
- **资源要求**：教学实现 O(n) 签名+小样本比对，CPU；大规模实现不是新生首课。

## DE-04 数据质量与分布审计

- **前置**：DE-02、ML-03。
- **目标**：能设计规则过滤、语言/内容分类、噪声/标签与分布偏差检查。
- **为什么在这里学**：去重不等于高质量，训练目标与数据来源会共同决定模型行为。
- **指定材料**：必学 [DCLM](https://arxiv.org/abs/2406.11794) 的数据筛选基准思想；推荐 [Data-Juicer](https://github.com/modelscope/data-juicer) 的算子分类作工具地图。
- **学习动作**：把质量规则写成可测指标；人工抽查各来源、长度、语言/标签的保留与丢弃样本。
- **最小实践**：生成质量报告：总量、保留率、字段缺失、长度/来源分布与抽样结果；检查某个过滤规则是否 disproportionately 删除某来源。
- **完成标准**：报告同时有统计和样例，指标不把代理目标当真实质量；标签噪声有人工复核入口。
- **卡住时**：回 DE-00 查采样来源，回 ML-03 查标签与指标；不要用模型给自身数据打分后免检。
- **下一步**：DE-05。
- **资源要求**：CPU 小样本；分类模型仅可选。

## DE-05 无泄漏拆分与评测污染

- **前置**：ML-00/03、DE-03。
- **目标**：能按 group/time 拆分并检查近重复跨集合和评测污染。
- **为什么在这里学**：随机拆分会放大同源、同人和时间相关数据的泛化表现。
- **指定材料**：必学 MOOC [group split](https://inria.github.io/scikit-learn-mooc/python_scripts/cross_validation_grouping.html) 与 [time split](https://inria.github.io/scikit-learn-mooc/python_scripts/cross_validation_time.html)。
- **学习动作**：先定义独立单位和时间边界，再拆 train/validation/test；去重需考虑跨集合，不只各集合内部。
- **最小实践**：示例按 group 和时间分配拆分，断言组不相交且没有超阈值近重复跨集合。
- **完成标准**：能写出拆分键、日期、比例和泄漏检查；基准文本进入训练语料时有污染处理说明。
- **卡住时**：回 DE-03 检查相似度与分组；样本过少先补合法数据或简化评价，不强行拆出空测试集。
- **下一步**：DE-06。
- **资源要求**：CPU。

## DE-06 采样、混合、Tokenization 与版本

- **前置**：DE-01…05。
- **目标**：能配置采样/重加权/混合，理解 tokenization 与数据版本 hash。
- **为什么在这里学**：数据比例和切分单位是训练配置，不是不可见的预处理细节。
- **指定材料**：必学 [HF Datasets](https://huggingface.co/docs/datasets/) 的处理/流式入口；推荐 [Dolma](https://arxiv.org/abs/2402.00838) 的配比与处理案例、[Hugging Face Tokenizers](https://huggingface.co/docs/tokenizers/)。
- **学习动作**：区分样本权重、来源混合、类别重采样；记录 tokenizer 版本、词表和文本规范，不能用字符数替 token 数。
- **最小实践**：把过滤阈值、seed、来源 hash、输出记录和依赖版本写成配置；改动一条规则，比较版本 hash 与保留率。
- **完成标准**：相同输入/配置得到相同输出版本；不同配置不会被同名文件悄悄覆盖。
- **卡住时**：回 PR-02 检查记录；混料异常先固定一个来源做基线。
- **下一步**：DE-07。
- **资源要求**：CPU；不需要下载大模型 tokenizer 权重。

## DE-07 大规模流程案例解读

- **前置**：DE-01…06。
- **目标**：能解释 DataTrove/Data-Juicer/FineWeb/DCLM 各自解决的问题与复用边界。
- **为什么在这里学**：先懂流水线，再决定是否需要分布式框架。
- **指定材料**：必学 [DataTrove](https://github.com/huggingface/datatrove) README 的 pipeline/processing 入口；推荐 [FineWeb](https://arxiv.org/abs/2406.17557)、[DCLM](https://arxiv.org/abs/2406.11794)、[Data-Juicer](https://github.com/modelscope/data-juicer)。
- **学习动作**：画来源→读取→过滤→去重→导出→统计；标出单机与分布式的差别、容错与中间产物。
- **最小实践**：写一页案例对照：哪个规则/阶段可复用、输入输出和统计是什么、自己小项目是否需要该工具。
- **完成标准**：不把工具名当质量证明；能指出原论文/仓库实证条件与自身数据差异。
- **卡住时**：回 DE-01…06 定位具体阶段；不为“规模大”引入无法维护的集群。
- **下一步**：DE-08。
- **资源要求**：阅读+CPU；不把 TB 级 Common Crawl 下载当作业。

## DE-08 毕业任务：可追溯数据产物

- **前置**：DE-00…07。
- **目标**：从合法公开小文档集合一键生成训练/验证/测试数据与审计证据。
- **为什么在这里学**：把分散规则变成可交接的数据工程闭环。
- **指定材料**：复用本仓 `examples/data_pipeline.py` 与 dataset card 文档；深入再选 DataTrove。
- **学习动作**：输入只读 → schema → 清洗 → 去重 → 质量报告 → 无泄漏拆分 → 配置/版本 hash → 导出与卡片。
- **最小实践**：用本仓示例或自建 20–100 条合法文本，保存 JSONL/Parquet、stats、dataset card 和运行命令；二次运行比对 hash。
- **完成标准**：另一人可从干净环境复现；每个删除有原因，拆分无已知近重复泄漏，限制和许可写得清。
- **卡住时**：按 DE-00…06 的阶段定位，不删除失败检查来让流水线通过。
- **下一步**：接 DL-03 小训练、LLM 数据桥或 ML-08 评估。
- **资源要求**：CPU 小样本；大模型预训练不是毕业条件。

## 本仓示例的边界

示例的 MinHash/LSH 为教学实现，不能替代大规模生产库；token Jaccard 查不出所有语义改写。数据集只用于教学，不是通用质量基准。当前维护者已在本地 CPU 跑通，但尚未开展新成员试走。
