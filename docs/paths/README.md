# 学习路径与成熟度

所有路径先过[起点自检](../start-here.md)。成熟度只表示内容与验证证据，不表示学习效果：

- **内容完成，待试走**：节点和实践已写、维护者做过技术核验，但未有新成员完整试走。
- **导览级**：只提供定位、先修、代表资源与一个入门任务，不是完整课程。
- **已试走**：必须有真实学习者的起点、卡点、恢复和完成证据；当前没有任何路径获得此标记。
