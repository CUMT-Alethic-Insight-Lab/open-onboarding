# AI 学科地图：四条轴，而不是一棵 LLM 树

这份地图回答“一个方法在学科里的位置”，不规定学习顺序。学习请从 [Start Here](../start-here.md) 进入；资源广度见 [awesome-ai](https://github.com/CUMT-Alethic-Insight-Lab/awesome-ai)。一个工作可同时属于多个格子，例如 CLIP 是连接主义 + 自监督/对比信号 + 双编码 Transformer + 视觉语言表征。

## 1. 四条正交轴

| 轴 | 回答的问题 | 主要类别 | 常见误读 |
| --- | --- | --- | --- |
| 研究范式 | 用什么样的知识与计算观解决问题 | 符号主义、概率/统计学习、连接主义、进化/群体、强化学习、生成式建模、混合系统 | 把新范式当作旧范式完全消失 |
| 学习信号 | 参数或行为依据什么反馈调整 | 监督、无监督、自监督、半监督、弱监督、在线/主动、模仿、强化 | 把“无人工标签”都称无监督 |
| 模型/算法家族 | 用什么结构或搜索过程表示解 | 线性/树、核/概率图、MLP/CNN/RNN/LSTM/Transformer/GNN/SSM、VAE/GAN/Diffusion/Flow、检索/规划/工具 | 把 Transformer 当学习信号或任务 |
| 任务与领域 | 对什么输入输出负责，怎样评价 | NLP、CV、多模态、音频、推荐、时序、图、机器人、科学 AI、遥感、因果、数据、评测/Infra、安全 | 用榜单成绩代替真实任务约束 |

```mermaid

    P[研究范式] --> M[模型/算法家族]
    S[学习信号] --> M
    M --> T[任务与领域]
    T --> E[数据、评测与系统约束]
    E --> S
```

文字替代：范式与学习信号共同约束算法选择；算法服务任务；任务所处的数据、评测和系统约束又反过来决定可获得的学习信号。这不是单向“技术越新越好”的流程。

## 2. 研究范式：多条仍然有效的路线

- **符号主义（symbolic AI）**：状态空间搜索、逻辑、知识表示、约束满足、专家系统。优势是可显式表达规则与推理；难点是知识获取、不确定性与开放环境。现代工具 Agent 仍会调用搜索和规划，而非所有推理都交给参数记忆。
- **概率/统计学习（probabilistic/statistical learning）**：从数据估计预测关系与不确定性，含线性/树/核方法、概率图与贝叶斯推断。表格数据、小样本和可审计基线仍离不开它，入口是[经典 ML](../foundations/classical-ml.md)。
- **连接主义（connectionism）**：用分布式参数表示和梯度学习构建神经网络；架构从 MLP/CNN/RNN 到 Transformer/GNN/SSM，入口是[DL 基础](../foundations/neural-networks.md)。
- **进化与群体方法（evolutionary/swarm）**：以变异、选择或群体互动搜索解，适合梯度不易获得或结构优化；不能把任何随机搜索都称遗传算法。
- **强化学习（reinforcement learning）**：通过与环境交互的奖励优化序贯决策，不同于给固定标签的监督学习；先修 ML/DL，再补 MDP/价值与策略梯度。
- **生成式建模（generative modeling）**：学习数据分布或可采样过程，VAE、GAN、Diffusion/Flow 与自回归模型是不同机制，不等价于“聊天模型”。
- **混合系统（hybrid/neuro-symbolic/tool-using）**：组合学习、检索、逻辑、规划与工具。关键是各组件接口、误差传播和可验证性，不是简单拼名词。

## 3. 学习信号：监督不是唯一来源

| 信号 | 信号从哪里来 | 一个合适的入门问题 | 下一步 |
| --- | --- | --- | --- |
| 监督 supervised | 人工/过程标注的目标 | 表格分类、图像分类 | ML-02、DL-03 |
| 无监督 unsupervised | 未标注数据的结构 | 聚类、密度估计、降维 | ML-07 |
| 自监督 self-supervised | 从数据自身构造预测目标 | 掩码/下一 token、图像增强一致 | DL-09 |
| 半/弱监督 semi/weak | 少量标签或噪声/间接标签 | 未标注数据如何利用、标签噪声怎样评估 | 先 ML-03 再读专题 |
| 在线/主动 online/active | 到达的新样本或选择查询 | 分布漂移、标注预算 | 先 ML-08 的稳健拆分 |
| 模仿 imitation | 专家状态—动作轨迹 | 行为克隆、分布偏移 | DL-03 → 机器人导览 |
| 强化 reinforcement | 环境回报与信用分配 | 价值/策略优化 | RL 桥接 |

## 4. 模型家族与计算约束

| 家族 | 核心表示/机制 | 适合先想的事 | 代价或失败模式 |
| --- | --- | --- | --- |
| 线性、树与集成 | 线性边界、递归划分、并行/串行组合 | 表格、小数据、基线 | 特征交互、外推、对分布的假设 |
| 核方法与概率图 | 相似度内积、变量条件依赖 | 中小数据、结构化不确定性 | 核计算规模、推断复杂度、依赖假设 |
| MLP/CNN/RNN/LSTM | 全连接、局部共享、顺序状态与门控 | 通用向量、图像、序列 | 参数冗余、局部性限制、串行与长依赖 |
| Transformer/GNN/SSM | 内容注意力、消息传递、状态空间序列递推 | 集合/序列/图结构 | 注意力 pairwise 成本、图结构质量、实现与硬件约束 |
| VAE/GAN/Diffusion/Flow | 概率潜变量、对抗、去噪、可逆/概率流 | 生成、表征、密度建模 | 后验/训练稳定、采样成本、模式覆盖、评测 |
| 检索/规划/工具 | 外部记忆、搜索树、可执行接口 | 知识更新、组合问题、行动 | 检索误差、搜索成本、工具失败与权限 |

参数量少不自动等于推理便宜；训练可并行也不自动等于服务延迟低。进入[高效 AI 路径](../paths/efficient-ai.md)后必须同口径实测。

## 5. 任务与领域入口

| 领域 | 典型问题 | 公共先修与桥接 |
| --- | --- | --- |
| NLP/LLM | 文本表征、生成、理解与工具调用 | ML → DL-06/07 → Tokenizer/语言建模/数据 |
| CV/VLM | 分类、检测/分割、视觉语言对齐 | ML → DL-05/07 → ViT/CLIP |
| 语音/音频 | ASR、TTS、音频理解/生成 | ML/DL → 波形/频谱 → 对应任务；ASR 不等于 TTS |
| RL/Alignment | 序贯决策、偏好与奖励优化 | ML/DL → MDP/价值/PPO → 后训练 |
| RAG/Agent | 检索、规划、工具执行 | Python/HTTP/JSON → 检索质量 → Schema/错误处理 |
| Infra/Evaluation | 训练/服务成本与可信度量 | DL 训练循环 → 性能分析；ML-03 → 基线/统计/污染 |
| 推荐/时序/图 | 排序召回、预测、节点/边/图任务 | ML → 领域拆分与结构 → 专门模型 |
| 机器人/VLA | 感知、控制、规划、动作生成 | DL/RL/模仿 → 状态估计/安全约束 |
| 因果/科学 AI | 干预/反事实、科学结构与预测 | 统计 → 因果假设/领域知识，不把相关性当因果 |
| 遥感/地学 CV | 多光谱、地理空间、时空预测 | DL-05 → 领域数据/坐标/评价，不复制通用 CV |
| 数据/高效 AI | 可追溯数据与质量—成本权衡 | DE-00 与 EA-1 入口见[路径目录](../paths/README.md) |

各领域的具体导览和成熟度集中在[方向路径](../paths/README.md)维护，未完成课程不会标成课程级。

## 6. 如何使用地图

1. 给新方法分别写下四轴标签，尤其分清学习信号和架构。
2. 找到公共先修，不从历史名气直接跳框架。
3. 写清任务的数据边界与评价，再比较模型。
4. 想理解“为何出现”读[多线发展史](../history/ai-history.md)；想知道“下一步学什么”回[学习路径](../paths/README.md)。
